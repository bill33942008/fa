# 金币冲冲冲（微信小游戏示例）

这是一个**上手门槛低、单局节奏快、后期逐步变难**的微信小游戏 Demo，核心目标：

- 单指操作，随时开一局
- 前期友好，后期有挑战
- 带有基础留存机制（连击反馈 + 每日目标 + 连续打卡）
- 已实现好友排行榜（云数据 + 本地兜底）
- 已实现道具系统（护盾 / 磁铁 / 慢速）
- 已实现双倍奖励看广告
- 内置微信广告接入封装（Banner / 激励视频 / 插屏）
- 内置埋点统计面板（留存、完成率、ARPU）

---

## 1. 玩法设计（傻瓜式）

### 核心规则

- 玩家控制底部接盘左右移动
- 接到金币加分，碰到炸弹本局结束
- 可通过观看激励视频广告复活 1 次
- 结算后可看广告领取双倍金币

### 难度曲线

- 随存活时间提升 `level`
- 每升一级：
  - 掉落速度增加
  - 刷新间隔变短
  - 炸弹比例提高
- 早期几乎全是金币，便于新手进入状态；后期炸弹密度高，考验专注

### 黏性设计

- **连击倍率**：连续接到金币会触发倍率，刺激继续玩
- **每日目标**：每天随机目标分（如 30~120），达成后额外奖励
- **打卡连续天数**：中断会重置，促进日活习惯
- **好友排行榜**：默认显示好友榜，拉不到云数据时自动降级到本地榜

### 道具系统（已实现）

- **护盾（盾）**：抵挡 1 次炸弹碰撞
- **磁铁（磁）**：一段时间自动吸附附近金币
- **慢速（缓）**：一段时间全场下落减速

## 3. 本地运行（微信开发者工具）

1. 打开微信开发者工具
2. 选择“小游戏”项目，导入当前目录
3. `project.config.json` 中 `compileType` 已配置为 `game`
4. 直接预览运行

> 当前 `appid` 使用 `touristappid`（仅开发调试）。上线前请替换为你自己的小游戏 AppID。

## 4. 广告接入方案（你要的“流量王”变现）

> 广告代码封装在 `src/ad-manager.js`，统一管理，方便后续扩展。

### 4.1 你需要替换的广告位 ID

文件：`src/config.js`

```js
const AD_UNIT_IDS = {
  banner: "adunit-xxxxxxxxxxxxxxxx",
  rewardedVideo: "adunit-yyyyyyyyyyyyyyyy",
  interstitial: "adunit-zzzzzzzzzzzzzzzz",
};
```

请替换成你在“微信广告”后台创建的真实广告位。

### 4.2 广告触发策略（已实现）

1. **Banner 广告**
   - 菜单页、结算页展示
   - 进入对局时隐藏（避免遮挡、提升体验）

2. **激励视频广告**
   - 结算页可点击“看广告复活”
   - 完整观看才复活，且每局仅 1 次
   - 结算后还可触发“看广告双倍奖励”

3. **插屏广告**
   - 每 N 局（默认 3 局）展示 1 次
   - 参数在 `GAME_CONFIG.retention.interstitialGapRounds`

### 4.3 变现建议（落地版）

- 新手期降低插屏频率，保护留存；中后期再逐步提高
- 激励视频给“复活/双倍奖励”等强动机入口，eCPM 一般高于 Banner
- 每日目标奖励可和激励视频结合（如“再看一次视频，奖励翻倍”）
- 强烈建议记录关键指标：`D1留存 / 单用户广告展示次数 / 激励视频完成率 / ARPU`

## 5. 埋点统计（已内置）

- 文件：`src/analytics.js` + `src/app.js` 的“埋点看板”
- 已记录并展示：
  - **留存**：D1 是否达成、活跃天数
  - **完成率**：`roundsSettled / roundsStarted`
  - **激励视频完成率**：`rewarded.completed / rewarded.requested`
  - **ARPU（估算）**：按广告展示估算广告收入（单用户）

> 当前 ARPU 为本地估算值，正式上线建议接入服务端埋点平台做真实收入归因。
